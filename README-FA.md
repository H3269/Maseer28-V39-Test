# Maseer28 V72 — All Reader Fixes

این بسته بر پایه همان نسخه V72 ارسالی کاربر ساخته شده است. محتوای چهار کتاب تغییر نکرده و فقط لایه نمایش/ناوبری و پیشنهاد مطالعه اصلاح شده است.

اعمال‌شده روی هر چهار کتاب:
- کشیدن به چپ: صفحه بعد
- کشیدن به راست: صفحه قبل
- کلید ←: صفحه بعد
- کلید →: صفحه قبل
- نوار صفحات پایین RTL و شروع صفحه ۱ از سمت راست
- حفظ صفحه‌بندی ۱۶ سطری و شروع مستقل فصل/پیوست
- حذف Boldهای ناخواسته متن عادی ناشی از استایل Word
- اصلاح فاصله داخل گیومه فارسی «...» در لایه نمایش
- راست‌چین شدن پایان جمله و جلوگیری از کشیدگی مصنوعی فاصله بین کلمات
- نمایش عنوان «منبع» در پیشنهاد مطالعه برای جلدهای ۱، ۲ و ۳ و کتابچه تکمیلی

فایل‌های محتوایی تعبیه‌شده کتاب‌ها با V72 اصلی یکسان نگه داشته شده‌اند.
